# План: Мессенджер с распределением заказов, ИИ и дашбордом

Стек: TanStack Start + Lovable Cloud (БД, auth, realtime) + Lovable AI (Gemini).

## Роли
- **Владелец** — создаёт логины, чаты, заказы, видит дашборд.
- **Сотрудник** — входит по логину/паролю, видит только свои чаты, откликается на заказы, отвечает ИИ в личке.

## Модули

### 1. Auth и пользователи
- Email + пароль (владелец задаёт оба через Auth Admin API).
- Таблица `profiles` (display_name) + `user_roles` (owner/worker, через security-definer `has_role`).
- Страница `/auth` (вход), `/admin/users` (владелец: создать сотрудника, сбросить пароль).

### 2. Чаты
- Таблицы `chats`, `chat_members` (user_id + chat_id).
- RLS: сотрудник видит чат только если он в `chat_members`.
- Страница `/chats` — список доступных чатов, `/chats/:id` — окно чата с realtime-сообщениями.
- Владелец на `/admin/chats` управляет чатами и составом.

### 3. Заказы
- Таблица `orders` (number, date, finish_date, nomenclature, customer_order, comment, responsible_user_id, chat_id, status: `new`/`in_progress`/`stalled`/`completed`/`overdue`, follow_up_interval_minutes).
- Создание: ручная форма + загрузка Excel/CSV (парсинг по колонкам с фото: Дата/Номер/Номенклатура/Финиш/Заказ покупателя/Комментарий/Ответственный).
- Владелец выбирает чат-получатель и интервал ИИ-фоллоуапов на каждый заказ.

### 4. ИИ-ассистент
- Server function: при создании заказа Gemini генерирует красивое сообщение с деталями и постит в чат от имени "AI Assistant".
- Кнопка «Откликнуться» в сообщении → создаёт запись `order_assignments`, ставит статус `in_progress`, ответственного.
- Cron (pg_cron → `/api/public/cron/followups` с секретом): каждые N минут проходит по активным заказам с просроченным `next_follow_up_at`, ИИ пишет в личный чат исполнителю «Привет, на какой стадии заказ X?».
- Ответы исполнителя в личке ИИ-агентом классифицируются (в работе / завис / готов) → обновляет статус заказа и `last_update_at`.
- Если нет ответа > порога → статус `stalled`.
- Если `finish_date` прошла, а не `completed` → `overdue`.

### 5. Дашборд владельца `/dashboard`
- Карточки-метрики: всего / в работе / завис / выполнено / просрочено.
- Таблица заказов с фильтрами по статусу, чату, ответственному.
- График загрузки по сотрудникам, realtime-обновления.

## Маршруты (TanStack)
- `/auth` — публичный вход
- `/_authenticated/dashboard` — владелец
- `/_authenticated/admin/users`, `/admin/chats`, `/admin/orders`, `/admin/orders/import`
- `/_authenticated/chats`, `/chats/$chatId`
- `/_authenticated/dm` — личные чаты с ИИ
- `/api/public/cron/followups` — endpoint для pg_cron

## Технические детали
- Lovable Cloud: Postgres + Auth + Realtime.
- Каждый сотрудник имеет автосозданный личный чат с ИИ (`is_dm=true`).
- Server functions для всех мутаций (создание заказа → ИИ → пост в чат) с `requireSupabaseAuth` + проверкой роли owner.
- Импорт Excel: `xlsx` пакет на сервере, маппинг колонок из шаблона на фото.
- Realtime подписка на `messages` и `orders` для мгновенных обновлений UI и дашборда.
- AI: `google/gemini-3-flash-preview` через Lovable AI Gateway.

## Дизайн
Тёмная тема, плотный «операционный» UI: сайдбар со списком чатов слева, окно чата по центру, панель деталей заказа справа. Дашборд — карточки + таблица в стиле админки. Шрифт Inter/Manrope, акцент — синий.

## Очерёдность сборки
1. Lovable Cloud + схема БД + RLS + роли.
2. Auth и страница `/auth`, создание сотрудников.
3. Чаты + realtime сообщения.
4. Заказы (форма + импорт Excel) + привязка к чату.
5. ИИ: генерация сообщения заказа, кнопка отклика.
6. Личные чаты + cron фоллоуапы + классификация ответов.
7. Дашборд с метриками и фильтрами.
